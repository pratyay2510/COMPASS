# COMPASS: Finding Where Reasoning Lives in Language Models

Inference-time steering that elicits reasoning from a frozen LLM using only
the correctness of its own direct answers: a per-head correctness direction,
a logit-space attribution score that finds the few heads carrying it, and a
single steered pass over the test split.

The code, setup and step-by-step instructions are in
[`COMPASS/README.md`](COMPASS/README.md).
